# Security

scn3 reads your file system and can move files to the trash, so security bugs matter.

## Reporting a problem

Please report it privately: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue.

Include what you found, how to reproduce it, and the version and OS. You will get an answer within a week.

## Supported versions

Only the latest release gets fixes.
